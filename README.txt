نموذج أولي غير مبني وغير مختبر. افتح المجلد في Android Studio مع JDK 17 وSDK 35 ثم Build APK. يتطلب Google Play Services. التسجيل يفتح صفحة الشراء الحالية في المتصفح ولا يغير السيرفر. لا توجد مزامنة رصيد داخل التطبيق أو إدارة عن بعد أو رابط تحميل بالباركود بعد. اختبر الخروج من النطاق ثم الدخول مع صلاحيات الموقع طوال الوقت والإشعارات. لا يعمل بعد إيقاف التطبيق إجباريًا وقد يتأخر الإشعار. النطاق 200 متر والإحداثيات من إعادة توجيه رابط الخرائط. لا تنشر للعملاء قبل الاختبار والتوقيع.

البناء عبر GitHub: أنشئ مستودعًا منفصلًا باسم almajedi-vip (Private)، وارفع محتويات هذا المجلد بما فيها .github/workflows/android.yml. من Actions اختر Build Almajedi VIP APK ثم Run workflow. بعد النجاح نزّل Almajedi-VIP-test-APK من Artifacts وفك الضغط. النسخة debug للاختبار فقط، وليست للنشر العام. لم يتم تشغيل البناء في البيئة الحالية.
